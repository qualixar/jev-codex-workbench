# Diagram sources

These are editable Mermaid diagrams, not screenshots of a running deployment.
01–05 show the implemented components and workflows; 04 has a clearly dashed optional
context adapter. 06 is entirely future integration guidance for existing systems.

Render with an already approved local Mermaid renderer or documentation tool. Do not
upload private diagrams to a public rendering service. Keep text alternatives from
ARCHITECTURE.md alongside published images, use a single reading direction, and show
local/remote and implemented/proposed boundaries. Native diagrams have not been rendered
by this package's bootstrap; their source files are provided for later editorial work.
